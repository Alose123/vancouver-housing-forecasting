# Sanitized Version 1.0 source archive

The sanitized Version 1 source bundle is intended to mirror the public **Stages 1–8** project.

It includes implementation, scripts, tests, stage contracts, and documentation while excluding restricted third-party raw data and bulky generated outputs.

The prospective post-holdout price-prediction stage is intentionally **not part of public Version 1.0**.

Researchers reproducing the project should obtain underlying housing-source materials directly from the original publishers under the applicable terms and preserve the project's source/category/timing definitions.
