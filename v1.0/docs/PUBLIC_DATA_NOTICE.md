# Public data and artifact notice

The complete private Version 1 research package includes third-party source files and generated stage outputs used to verify the analysis. Those materials are intentionally not mirrored into this public GitHub repository.

`THIRD_PARTY_NOTICES.md` records the project's interpretation of source terms. In particular, the retained CREA HPI material is not treated as openly redistributable. Public availability of a source is not assumed to grant republication rights.

The public repository therefore focuses on:

- source code;
- orchestration logic;
- stage contracts;
- tests;
- methodological documentation;
- a final report containing derived aggregate results;
- reproducibility metadata/design descriptions.

Researchers wishing to reproduce the study should obtain source material directly from the original publishers under the applicable terms and verify that definitions/vintages match the project contracts.
