# Vancouver Housing Forecasting — Version 2.0 (planned)

Version 2.0 is intentionally not implemented yet. Version 1.0 remains frozen as the baseline research system.

## Primary research question

> **How much incremental forecast accuracy can richer local-market, property-level and economic information provide beyond a simple persistence forecast of Greater Vancouver housing prices, and how stable is that improvement across horizons and market conditions?**

## Planned priorities

1. Expand the monthly panel across more geographies × property types.
2. Add real-time/vintage-aware source fields where feasible.
3. Add economically justified housing-market predictors with publication timing.
4. Evaluate hierarchical/panel and ensemble forecasting.
5. Add probabilistic forecasts with calibration checks.
6. Add transaction-level/hedonic modelling if a legally usable dataset becomes available.
7. Increase agent analytical discretion while preserving hard leakage/governance guardrails.
8. Preserve future observations as genuine prospective evaluation periods.

See [Version 1 limitations and future directions](../v1.0/docs/LIMITATIONS_AND_FUTURE_DIRECTIONS.md) for the detailed rationale.
